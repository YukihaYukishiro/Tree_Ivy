Tree_Ivy とは

Tree_Ivy は、学習管理システム（LMS）を利用する学生向けに設計された Chrome 拡張機能です。
ブラウザ上で動作するスクリプトにより出欠状況やスケジュールを、視覚的に・直感的に確認できるようにします。

現在無料ですが、投げ銭は作者のPayPay（calmia_yf）で歓迎します。

使い方のページを見る

主な機能

  • ・ 出欠・授業情報を見やすく整理
  • ・ カレンダーUIの視認性向上
  • ・ カスタマイズ可能な表示設定
  • ・ レイアウト改善によるスムーズな出席登録
  • ・ 重要な情報を通知でお知らせ
  • ・ 分割表示で複数の情報を同時に確認
  • ・ その他複数の学習体験の改善を目的とした機能
  • ・ 不必要な通信の削減によるパフォーマンス向上
